# Recipe Box

Recipe Box is a mobile application project created with FlutterFlow. It helps users explore recipe ideas and browse meals by category.

## Features

- Welcome screen
- Search field for recipes and ingredients
- Breakfast, Lunch, and Dinner categories
- Featured recipe section
- Cooking Tip of the Day
